# Hybrid Actions

Distributed GitHub Actions workers for approved public game DEMO catalogues. The runner fleet consumes durable tasks from the existing Hybrid Cloud Fuzzer Cloudflare D1/R2 control plane. Browser sessions are isolated by game and provider; no real-money sessions, spins or purchases.

Initial setup is in progress. The production workflow will remain manual/opt-in until Cloudflare endpoints, policies and GitHub secrets are verified.
